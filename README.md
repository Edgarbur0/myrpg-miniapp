# 🏯 Сянься — Mini App для ВКонтакте

Клиент мини-приложения Сянься RPG. Запускается в ВКонтакте через VK Bridge, данные берутся из API на сервере.

## Структура

```
myrpg-miniapp/
├── index.html   ← экраны (Персонаж / Инвентарь / Культивация / Техники)
├── style.css    ← стили, тёмное фэнтези + восточный колорит
├── app.js       ← логика, VK Bridge, запросы к API
└── README.md    ← этот файл
```

## Зависимости

| Ресурс | Источник |
|--------|----------|
| VK Bridge | CDN `@vkontakte/vk-bridge` |
| Шрифт Roboto | Google Fonts |
| API | `https://edgarburo.ru/api` (CORS: `*.github.io`) |

## Деплой на GitHub Pages

### 1. Репозиторий

1. Создай новый **публичный** репозиторий (например, `myrpg-miniapp`).
2. Загрузи все 4 файла в корень.
3. В **Settings → Pages → Source** выбери ветку `main`, папку `/ (root)`.
4. После публикации URL будет: `https://<username>.github.io/myrpg-miniapp/`

### 2. Привязка к ВК (VK Mini Apps)

1. В **VK Dev** (dev.vk.com) создай приложение → тип **Mini App**.
2. В настройках приложения:
   - **URL**: `https://<username>.github.io/myrpg-miniapp/`
   - **Платформа**: VK Bridge (Universal / Web)
3. **Запуск**: через URL в сообществе или по ссылке `vkapps://...`.
4. Для отладки без публикации: используй **BSU** (Building & Serving Utility) ВК.
   ```
   npx @vkontakte/vk-mini-apps-cli serve
   ```

### 3. VK Bridge в браузере

При открытии **вне VK** (обычный браузер) Bridge недоступен — приложение использует
тестовый `user_id = 416584639` для просмотра интерфейса.

## Экраны

| Вкладка | Данные |
|---------|--------|
| Персонаж | `GET /player/<id>` |
| Инвентарь | `GET /player/<id>/inventory` |
| Культивация | из данных персонажа |
| Техники | `GET /player/<id>/techniques` |
| Использование зелья | `POST /player/<id>/use_potion` |
